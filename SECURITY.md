# Security policy

## Reporting a vulnerability
Please report vulnerabilities privately via GitHub's
["Report a vulnerability"](../../security/advisories/new) form rather than a public issue.
Expect an initial response within a week.

## Scope notes
- Last.fm API credentials and session keys are stored only in the system keyring.
- The app reads user-supplied audio files and theme JSON; reports about crashes or
  unsafe handling of malformed input are welcome.
